# Emotion Detector

## Project Description

Emotion Detector is an AI-based web application that identifies emotions expressed in text using the IBM Watson Natural Language Processing (NLP) library.

The application detects five emotions:

* Anger
* Disgust
* Fear
* Joy
* Sadness

It also identifies the dominant emotion in the input text.

## Technologies Used

* Python
* IBM Watson NLP
* Flask
* HTML
* CSS

## Project Objective

The objective of this project is to develop and deploy a web application that analyzes text and identifies the emotions expressed by the user.
